燕翔车队经费管理系统 V2.2.4
==========================

Windows 免安装版：进入“Windows软件”，双击“燕翔车队经费管理系统.exe”。
首次启动会自动建立数据库并载入 5 条可删除的演示数据。
首次启动可能因 Windows 安全扫描等待 1～3 分钟，请勿重复双击；后续启动通常会明显加快。

默认账号
管理员：admin / YXRT@2026（首次登录必须修改）
成员：member01～member08 / Member@2026（首次登录必须修改）
公共查看：viewer / View@2026（只读与导出）

重要提示
1. 请先用管理员账号修改默认账号与密码。
2. V2.2.4 会把业务数据迁移到 Windows 固定数据区，之后更换程序文件夹仍使用原人员、组别和发票。
3. 管理员可在“系统设置”导出完整备份；压缩包含数据库、附件及人员、组别、账号关联可查看清单。
4. “使用教程”文件夹内含 PDF 教程。
5. 没有云端服务器时保持“本地模式”即可；不影响 OCR、统计和台账功能。
6. “系统外观”可导入 Wallpaper Engine 壁纸，并维护登录页图片、GIF、视频轮播。
7. OCR 会离线填写建议分类和物品类型；管理员可在“智能分类规则”中维护关键词。
8. 人工确认金额、发票号和分类后再保存，历史修正会在本机辅助后续分类。
9. 发票台账可勾选多条记录后批量修改、删除或导出；导出完成会显示数量和金额。
10. 所有账号均可在“系统设置 → 版本与更新”选择自动完整备份并更新，或手动下载补丁包覆盖。
11. V2.1.1 及更早版本需先解压一次“WindowsUpdate”桥接补丁，以后即可使用软件内自动更新。
12. 首次升级后，原有数据自动归入 2026 赛季；新赛季需重新建立成员账号，长期组别继续保留。
13. 创作者名单全赛季共享，所有人可查看、仅管理员可编辑；新赛季无需重复添加。

软件版本：V2.2.4 Final
适用系统：Windows 10/11 64 位
