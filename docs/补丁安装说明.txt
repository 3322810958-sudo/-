燕翔车队经费管理系统 V2.3.3 轻量无损升级补丁
===========================================

适用范围
V2.2.0 及以上 Windows 免安装版；更早版本建议先安装一次 V2.2.1 桥接补丁。

安装步骤
1. 先在软件“系统设置”中导出一份完整备份。
2. 完全退出燕翔车队经费管理系统。
3. 打开补丁压缩包，将其中全部文件解压到原软件文件夹。
4. Windows 询问时选择“替换目标中的文件”。
5. 重新启动“燕翔车队经费管理系统.exe”，在设置中确认版本为 V2.3.3。

数据安全
补丁不包含也不会要求删除 data、uploads、models、tmp 或 .env。
V2.3.3 继续使用 Windows 固定数据区中的数据库、附件、模型和备份，不会重置人员、组别或账号。
以后即使把新版放入另一个程序文件夹，仍会读取固定数据区中的原人员、组别、账号和发票。
V2.3.3 轻量补丁只包含主程序、网页界面与更新说明，不重复打包业务数据、OCR 模型、运行库和教程 PDF。

本次变化
批量修改增加资金来源，证明附件增加缩略图与缩放预览，顶部栏和左侧导航支持透明度设置。
识别故障解决后自动移除，并缩短故障等待；管理员可在自动备份后清除当前赛季数据。

以后更新
所有账号均可进入“系统设置 → 版本与更新”检查、下载并安装后续最新版。
