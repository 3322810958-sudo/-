燕翔车队经费管理系统 V2.2.1 无损升级补丁
===========================================

适用范围
V2.0、V2.1、V2.1.1 等尚未包含自动更新入口的 Windows 免安装版。

安装步骤
1. 先在软件“系统设置”中导出一份完整备份。
2. 完全退出燕翔车队经费管理系统。
3. 打开补丁压缩包，将其中全部文件解压到原软件文件夹。
4. Windows 询问时选择“替换目标中的文件”。
5. 重新启动“燕翔车队经费管理系统.exe”，在设置中确认版本为 V2.2.1。

数据安全
补丁不包含也不会要求删除 data、uploads、models、tmp 或 .env。
账号、密码、发票、分摊、设置和版本记录保存在 data 中；发票附件、壁纸和登录轮播保存在 uploads 中；离线识别模型保存在 models 中。
首次进入 V2.2.1 时，原有业务数据会自动归入 2026 赛季，长期组别继续保留。

以后更新
完成本次桥接后，管理员可直接进入“系统设置 → 软件更新”检查、下载并安装后续最新版。
