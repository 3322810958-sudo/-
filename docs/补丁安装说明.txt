燕翔车队经费管理系统 V2.3.2 轻量无损升级补丁
===========================================

适用范围
V2.2.0 及以上 Windows 免安装版；更早版本建议先安装一次 V2.2.1 桥接补丁。

安装步骤
1. 先在软件“系统设置”中导出一份完整备份。
2. 完全退出燕翔车队经费管理系统。
3. 打开补丁压缩包，将其中全部文件解压到原软件文件夹。
4. Windows 询问时选择“替换目标中的文件”。
5. 重新启动“燕翔车队经费管理系统.exe”，在设置中确认版本为 V2.3.2。

数据安全
补丁不包含也不会要求删除 data、uploads、models、tmp 或 .env。
V2.3.2 继续使用 Windows 固定数据区中的数据库、附件、模型和备份，不会重置人员、组别或账号。
以后即使把新版放入另一个程序文件夹，仍会读取固定数据区中的原人员、组别、账号和发票。
V2.3.2 轻量补丁只包含主程序、网页界面与更新说明，不重复打包业务数据、OCR 模型、运行库和教程 PDF。

本次变化
修复升级后人员和组别恢复默认的问题。完整备份新增人员、组别、账号关联和发票明细清单；恢复后关联保持不变。
版本与更新页面可选择“自动完整备份并更新”或“手动下载补丁包并覆盖”。自动备份失败时不会继续安装。

以后更新
所有账号均可进入“系统设置 → 版本与更新”检查、下载并安装后续最新版。
