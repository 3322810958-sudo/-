燕翔车队经费管理系统 V2.2.3 轻量无损升级补丁
===========================================

适用范围
V2.2.0 及以上 Windows 免安装版；更早版本建议先安装一次 V2.2.1 桥接补丁。

安装步骤
1. 先在软件“系统设置”中导出一份完整备份。
2. 完全退出燕翔车队经费管理系统。
3. 打开补丁压缩包，将其中全部文件解压到原软件文件夹。
4. Windows 询问时选择“替换目标中的文件”。
5. 重新启动“燕翔车队经费管理系统.exe”，在设置中确认版本为 V2.2.3。

数据安全
补丁不包含也不会要求删除 data、uploads、models、tmp 或 .env。
账号、密码、发票、分摊、设置和版本记录保存在 data 中；发票附件、壁纸和登录轮播保存在 uploads 中；离线识别模型保存在 models 中。
V2.2.3 轻量补丁只包含主程序、网页界面与更新说明，不重复打包 OCR 模型、运行库和教程 PDF。

本次变化
创作者名单改为全赛季共享。现有名单自动保留，管理员在任意赛季修改后对全部历史和新建赛季生效。

以后更新
所有账号均可进入“系统设置 → 版本与更新”检查、下载并安装后续最新版。
