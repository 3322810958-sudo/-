# 燕翔车队经费管理系统 V2.2 运行与使用说明

## 快速启动

进入 `Windows软件` 文件夹，双击 `燕翔车队经费管理系统.exe`。软件会在本机启动专用服务并打开桌面窗口，不需要单独安装数据库。

若电脑缺少 Microsoft Edge WebView2，软件会自动改用默认浏览器。Windows 10/11 通常已经内置该组件。

## 默认账号

| 身份 | 账号 | 密码 | 权限 |
|---|---|---|---|
| 管理员 | admin | YXRT@2026 | 全部功能，首次登录强制修改 |
| 成员 01～08 | member01～member08 | Member@2026 | 维护账目、附件、分摊和结算，首次登录强制修改 |
| 公共查看 | viewer | View@2026 | 查看驾驶舱、台账、统计并导出 |

管理员可新增、停用和修改全部账号。每位成员也可在右上角菜单修改自己的账号和密码。

## 主要功能

### 发票台账与离线 OCR

在“发票台账”选择“新增发票”。可上传 JPG、PNG、BMP、TIFF、WEBP、PDF、TXT、OFD 或 ZIP。批量导入也可直接一次选择多个文件。录入窗口会显示缩略图，点击可居中放大、缩小或打开原文件。图片及扫描件使用本机 OCR，文本型 PDF 优先直接提取文字。识别结果会自动填入发票号、日期、销售方、金额、税额、费用分类和物品类型，保存前均可人工修改。

智能分类完全在本机运行。系统先匹配管理员维护的关键词规则，再参考已保存的同销售方和同类历史记录。内置规则覆盖耗材、紧固件、电器件、继电器、线束连接器、传感器、电池、复合材料、金属材料、机械加工、制动、传动、轮胎和差旅等常见车队采购。每次都应人工核对；人工修正并保存后，会成为本机后续判断的参考。

管理员可进入“系统设置 → 智能分类规则”新增、编辑、停用、删除或恢复默认规则。关键词以逗号分隔，优先级数字越大越先匹配。建议使用明确物料词，避免只填写“配件”“材料”等过宽关键词。

ZIP 或多文件导入会逐份建立草稿并并行识别。处理过程中显示随机赛车 0～100% 进度，完成后提示成功数量和识别总金额。单个附件采用流式写入，没有人为设置的固定大小上限；实际容量取决于磁盘空间、内存和反向代理设置。

台账左侧复选框可多选或全选记录，随后批量修改分类、报销状态、删除或仅导出选中项。每条记录同时显示开票日期、上传日期和提交人，便于追溯。

### AA 分摊

每笔发票可选择：

- 全队均摊；
- 指定成员均摊；
- 按权重分摊；
- 仅付款人承担；
- 不启用 AA，仅记录报销。

金额始终以“分”为最小单位计算。无法整除的尾差按成员顺序分配，所有成员份额之和始终等于发票总额。完成转账后，可在“AA 结算”登记还款，系统自动更新成员净额和建议转账路径。

### 分类、资金来源与报销

管理员和成员可在“系统设置 → 分类与资金来源”新增、修改、停用或重新启用项目；公共查看账号只读。资金来源可以是车队账目、大创报销、指导教师经费、赞助款、成员 AA、借款或自定义项目。每笔发票的资金来源、已报销金额和日期均可留空，确认后再补充。

发票台账可按分类筛选后使用“批量导出 PDF”：选择合并 PDF，或逐张生成 PDF 并打包 ZIP。源 PDF 不重绘，图片按原始像素无损封装。CSV 固定导出发票号码、总金额、分类、承担方式、资金来源和成员六列。

### 成员和账号

成员资料与登录账号相互独立：可先添加成员，再建立关联账号。停用成员不会删除历史账目。公共查看账号不能修改数据；只有管理员能管理账号、系统外观、同步、备份和版本回溯。

### 赛季、长期组别与创作者

管理员点击页面顶部的赛季名称，或进入“系统设置 → 赛季与长期组别”，可新建、切换、改名、归档或重新启用赛季。普通成员和公共查看账号不能切换或编辑赛季。

首次升级到 V2.2.1 时，已有成员、成员账号、发票、分摊、结算、日志和版本记录会自动归入 2026 赛季。切换到新赛季后，历史赛季数据不会删除，仍可由管理员切回查看；被归档的赛季只能查看，不能新增或修改数据。

新赛季不会沿用原成员或成员账号，管理员需要重新建立当季成员及其登录账号。管理员账号和公共查看账号会继续保留。长期组别跨赛季保留，可在赛季管理窗口增加，成员编辑时直接选择。

“创作者”页面对所有登录用户开放，显示姓名、赛季、组别、岗位和说明；只有管理员可以新增、编辑、隐藏或删除。系统默认包含“2026赛季 / 电气部 / 高压 / 刘松宁”，管理员可随时修改。

### 版本、日志与备份

系统在关键操作和同步前建立保护点，同时保留操作日志。管理员可手动创建版本，最多保留最近 100 个；回溯前系统还会再建立一个保护点。

完整备份包含数据库和附件。建议每周导出一次，并额外保存在移动硬盘或受控网盘。恢复备份会覆盖当前业务数据，系统会先自动建立保护点。

### 自定义界面

管理员可更改车队名称、强调色、背景图片或视频和遮罩浓度。媒体保存在本地附件目录，离线可用。若后续启用云端同步，外观设置也会随业务数据同步。

每台电脑可在清晰深色、护眼浅色和赛车蓝高对比模式间切换，并自定义常用操作快捷键。批量处理所用赛车图片也可在系统外观中添加、删除、排序或恢复默认。

登录页可循环播放图片、GIF 或视频。进入“系统设置 → 系统外观”，可一次上传多份媒体、修改标题和单张停留时长、拖动排序，并选择淡入淡出或滑动切换。登录框右侧的眼睛按钮可显示或隐藏密码；每次退出登录都会恢复为隐藏状态。

### Wallpaper Engine

点击“读取 Wallpaper Engine”后，软件会自动查找 Steam 创意工坊订阅目录和本地项目。图片、GIF、MP4、WEBM 可直接播放；场景、网页或应用型壁纸会使用其预览图，以保证软件稳定和离线运行。可将任一项目设为系统背景或加入登录轮播。

若未自动找到，请先在 Steam 中启动过 Wallpaper Engine，并确认项目已下载完成。软件不控制 Steam 客户端，也不会修改创意工坊文件；导入时会复制所选媒体或预览图到本软件附件目录。

## 软件更新与旧版本桥接

V2.2.0 及以后版本可由任意账号进入“系统设置 → 版本与更新”，点击检查更新、下载并安装。软件从 GitHub Release 获取最新包，校验 SHA-256 后退出、替换程序并自动重启；若替换失败会恢复旧程序并记录错误。

从 V2.2.0 更新至 V2.2.1 时会自动完成赛季数据库迁移，现有数据归入 2026 赛季；更新包不会清除任何业务数据。

V2.1.1 及以前版本尚未包含更新入口，需要关闭软件，把 `WindowsUpdate` 桥接补丁解压到原软件目录并同意覆盖。完成这一次桥接后，后续版本均可从设置页直接更新。

更新过程不会替换已有的 `data`、`uploads`、`models`、`tmp` 或 `.env`。账号、设置和账目位于数据库，发票、壁纸和登录轮播位于附件目录，因此均会保留。更新前仍建议导出一次完整备份。

## 数据位置

Windows 免安装版的数据库、附件和 OCR 模型均位于软件文件夹：

- `data/yanxiang_expense.db`：数据库；
- `uploads/`：发票及背景附件；
- `models/`：离线 OCR 模型；
- `tmp/`：运行时临时文件。

迁移到另一台电脑时，关闭软件后复制整个 `Windows软件` 文件夹。不要只复制可执行文件。

## 本地与云端同步

没有服务器时无需配置，软件完整离线运行。以后准备好 Linux 服务器后，由管理员在“系统设置 → 云端同步”填写 HTTPS 地址和同步密钥。断网期间的修改进入本地队列，联网后自动上传；服务器端更新也会拉回本机。附件使用 SHA-256 校验，重复文件不会反复传输。

同一记录在多端修改时，采用“更新时间优先、设备标识决胜”的规则。同步前会自动建立保护点；如需恢复，管理员进入“日志与回溯”操作。

## 常见问题

- OCR 首次识别稍慢：首次加载模型需要数秒，后续会明显加快。
- 扫描件识别不准：尽量使用清晰、端正、无遮挡的原图；保存前人工核对金额与发票号。
- 分类建议不准确：人工修改后保存，或由管理员补充更明确的关键词并提高规则优先级。
- Wallpaper Engine 列表为空：确认 Steam 库和订阅内容已在本机下载，再重新扫描。
- 视频背景卡顿：换用较短的 1080p MP4/WEBM，或改用静态预览图。
- 窗口打不开：确认 Windows 安全软件未拦截程序；也可打开浏览器访问 `http://127.0.0.1:8765`。
- 端口被占用：桌面软件会自动选择可用端口。
- 忘记密码：由管理员重置成员账号；管理员密码遗失时使用最近的完整备份恢复。
- 数据异常：先导出完整备份，再使用版本回溯；不要直接修改 SQLite 文件。
- 更新检查连接失败：确认可访问 `api.github.com`；也可下载 `WindowsUpdate` 补丁手动覆盖。
