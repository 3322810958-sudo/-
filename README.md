# 燕翔车队经费管理系统 V2.4.1

面向大学生方程式车队的离线优先经费、发票、AA 分摊与报销管理软件。Windows 桌面端可独立运行，也可部署到 Linux 服务器进行多端同步。

## V2.4.1 新增功能

- Excel 甘特图按任务编号增量导入，支持预检、更新与新增统计，重复导入不会生成重复任务。
- 计划页新增状态看板，以及优先级、组别、负责人组合筛选。
- 元件库支持 Excel 整表导入、供应商和采购资料、跨赛季统计、补货清单及 CSV 导出。

## V2.4 基础功能

- 全队计划中心：任务、子任务、前置依赖、部门与负责人多选、进度、优先级、状态及赛季甘特图。
- 计划按赛季隔离，归档赛季只读；支持 XLSX、CSV、TSV 预检导入和 7/3/1/0 天及逾期提醒。
- 电气部元件汇总库跨赛季保存，包含库存估值、低库存、采购入库、领用审批、批次和项目流水。
- BOM 支持批量入库与缺料分析，按贸泽料号、制造商型号、唯一名称和封装保守匹配。
- 可选贸泽 Search API，密钥只使用 Windows 本机加密保存；未配置时全部离线库存功能正常使用。
- 故事模式为每篇文章提供封面，优先使用车队图片；缺图时自动生成赛季主题封面。
- 补入夏怀成人物志与 2026 A06 参赛编号等公开史料索引，网络文章使用摘要、出处和原文链接。

## V2.3 主要功能

- 管理员可创建、切换、改名和归档赛季；发票、成员、账号、分摊及结算按赛季隔离，旧赛季可查看。
- 新赛季重新建立成员和成员账号，长期组别跨赛季延续；归档赛季自动只读。
- 创作者名单全赛季共享、所有人可查看且仅管理员可编辑，新赛季无需重复添加。
- 清晰深色、护眼浅色、赛车蓝高对比三种模式，并支持本机自定义快捷键。
- 删除、停用、回溯与恢复等重要操作使用软件内居中确认框。
- 发票图片、PDF、TXT、OFD、ZIP 或多文件直接批量导入；PP-OCRv5 完全离线识别。
- 批量任务显示随机赛车 0～100% 进度，赛车素材可由管理员替换。
- 发票台账支持多选、全选、批量改资金来源/分类/报销状态/删除/导出，并显示提交人、开票日期和上传日期。
- CSV 导出兼容 Windows 保存窗口，完成后提示发票数量与合计金额。
- 录入和批量导入支持附件缩略图、居中缩放预览和原文件打开；批量 PDF 可合并或逐张打包 ZIP。
- 管理员可维护录入默认值；提供七种高可读显示模式和五档背景清晰度。
- 自动填写发票号码、日期、销售方、金额、税额、产品类型与费用分类。
- 管理员可编辑分类关键词规则，并结合商家历史人工修正进行本地学习。
- 全队、指定成员、个人承担、等额与权重 AA 分摊，金额精确到分。
- 成员独立账号、管理员账号与公共只读账号。
- Wallpaper Engine 创意工坊扫描；图片、GIF、MP4、WebM 背景与登录轮播。
- 管理员可编辑登录轮播的顺序、标题、停留时间、切换效果与启停状态。
- SQLite WAL 长期存储、完整备份、审计日志、版本保护点及管理员回溯。
- 设置页可检查、下载并安装 GitHub Release；SHA-256 校验、数据保留和失败回滚均自动执行。
- 离线队列、附件 SHA-256 校验与可选云端双向同步。
- 简体中文赛车数据驾驶舱，电脑和手机浏览器自适应。
- OCR 低置信度、导入失败、PDF 导出失败分别使用不同颜色标记，并可从右下角故障中心直接定位。
- 发票可附加购物证明、签字证明及其他文件；导出时可把可转换附件追加为独立页面，无法转换的原文件保留在 ZIP 中。
- 支持成员头像、个人背景与自有音频，并可导入导出不含密码和账务数据的“姓名软件设置”压缩包。
- 登录页支持高对比半透明面板和管理员本机凭据找回；找回过程限速并记录审计日志。
- 问题反馈支持多格式附件本机打包；可选 QQ SMTP 或 GitHub 反馈仓库，公开内容自动隐藏姓名和联系方式。
- 管理员可在自动完整备份后清除当前赛季发票、成员、成员账号和个人设置，同时保留当前管理员、公共账号、组别、创作者及其他赛季。
- 故事模式免登录浏览，内置 2007—2026 公开历史时间线和出处链接；编辑仍需管理员登录。
- NAS 支持 Windows 映射盘与 SMB 共享目录，由管理员手动上传、校验、查看和恢复完整备份。

## 本地开发

需要 Windows 10/11 64 位与 Python 3.12。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe scripts\prefetch_ocr_models.py
.\.venv\Scripts\python.exe -m app.desktop
```

不安装 OCR 组件时，仍可开发账务、权限、界面与同步功能：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-core.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8765
```

## 测试

```powershell
.\.venv\Scripts\python.exe -m pytest tests -q --import-mode=importlib -p no:cacheprovider
```

## 默认开发账号

首次运行会生成可删除的演示数据，并创建开发用账号。所有管理员和成员账号首次登录后必须修改账号与密码。正式部署前请同时配置新的同步密钥。

## 数据安全

数据库、附件、OCR 模型、构建目录、备份包和环境变量均已加入 `.gitignore`，不会提交到源码仓库。发布前仍应执行一次敏感信息检查。

问题反馈默认只进入本机待发送队列。需要自动发送时，在 `.env` 中配置自有 QQ 邮箱 SMTP 授权码；也可配置专用 GitHub 反馈仓库和最小权限令牌。软件不会把姓名、联系方式或本地附件公开到 GitHub。

## 升级方式

- V2.2.0 及以后：所有账号均可进入“系统设置 → 版本与更新”，直接升级到最新版本。
- V2.1.1 及以前：首次使用 `WindowsUpdate` 桥接补丁，关闭软件后解压到原软件目录并同意覆盖；以后即可在软件内更新。
- V2.2.4 起业务数据位于 Windows 固定数据区；V2.3.9 的补丁升级会先建立完整备份，回溯旧补丁时同时恢复对应业务数据。`tmp` 仅存放可重新生成的临时文件。
- V2.3.9 补丁包含与主程序匹配的运行库；数据库、附件和个人设置不会被覆盖。
- V2.4.1 强化计划表 Excel 增量导入、任务看板和元件整表导入；补丁升级前仍会自动完整备份，旧赛季任务和全局库存均进入版本保护范围。

## Wallpaper Engine 兼容范围

视频、图片和 GIF 壁纸可直接在软件内播放。Wallpaper Engine 的场景、网页与应用型壁纸采用本地预览图，避免执行第三方脚本或专有场景包。
